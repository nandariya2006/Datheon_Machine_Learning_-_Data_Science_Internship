# Datheon Machine Learning & Data Science Internship

## Task 1- Project: Iris Flower Classification

### Objective
Build a supervised machine-learning model to classify Iris flowers into Setosa, Versicolor, and Virginica species using flower measurements.

### Dataset
The project uses `iris.csv`, containing sepal length, sepal width, petal length, petal width, and species.

### Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook in VS Code

### Work Completed
- Loaded and explored the dataset
- Visualized feature relationships using a pairplot
- Split data into training and testing sets
- Trained Logistic Regression and Decision Tree classifiers
- Evaluated models using accuracy, precision, recall, and F1-score
- Created confusion matrix heatmaps and decision-boundary visualizations

### How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn scikit-learn jupyter`
3. Open `Iris_Classification_Project.ipynb` in VS Code.
4. Ensure `iris.csv` is in the same folder.
5. Run the notebook cells in order.
